## Why "Microwave"

A microwave oven does not cook from scratch, it excites the water molecules
already present. Your wiki atoms are those molecules: the expensive context is
cooked once and reheated at cache-read price on every later session, instead of
being rediscovered from zero. That is the whole thesis (full version in the
README).

## Architecture in one breath

One recursive method over two object types (agents, features), two planes, one
registry:

- Meta plane (org-wide): the factory, the agent cards, the framework ADRs, the
  index the runtime reads.
- Product plane (per project): the work, its own ADRs, learnings, bugs, saves.
- Agents may create agents, but only through the factory. That single entry
  point of creation is the anti-sprawl invariant.

The long version is `docs/method.md`; the two-plane diagram is in the README.

## Gates (what is enforced)

Machine checks, a CI for agent creation. Green gates on the fast path mean
activate; the full path adds the devil loop and one human gatekeeper.

|---|---|

| `gate_brief` | the 3-section brief is complete |
| `gate_schema` | the agent card matches the template contract |
| `gate_testable` | every done-criterion names a check (form, not execution) |
| `gate_embodiment` | the agent has a body when it needs one |
